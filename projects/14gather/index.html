Gather: a collecting app

Gather started from a simple personal problem: I collect bottle caps, but friends and family never knew which ones I already owned or was missing. Existing collection-management tools felt outdated and overly manual, so I built Gather: an AI-powered social collection platform that allows users to instantly identify, organize, and share collectibles through a simple photo. Designed initially for bottle caps but scalable to any collectible, the platform transforms collecting into a collaborative and accessible experience.

I developed the mobile application using Expo and React Native, with Firebase powering the shared real-time database. The core technical challenge was the image-recognition system: each uploaded image is vectorized into a feature embedding and compared against the database using similarity-search algorithms to retrieve the six closest matches. This human-in-the-loop approach combines AI efficiency with user validation, achieving approximately 99% automated recognition accuracy while maintaining full reliability. Building the project required independently learning and integrating machine learning workflows, vector similarity search, cloud infrastructure, and mobile deployment.

Since January 2026, Gather has been actively used by a growing group of collectors who continuously contribute to the shared database. More than a technical project, Gather reflects my passion for engineering and my ability to learn complex technologies from scratch to build a fully functional product solving a real-world problem.
